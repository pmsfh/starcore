## v1.56 — 功能: 战斗过程演出（战报逐条播出）


**变更性质：功能（战报逐条播出、结果弹窗延后出场，机制数值零变化）**

**开发时间：2026-10-11**

### 概述

此前点击出征后结果弹窗与完整战报同帧出现，战斗缺少过程感。
本版让页内战报逐条播出：日志按条入场，播完或跳过后结果弹窗
才出场；奖励与战损仍在结算时即时落袋，机制与数值零变化，
兼容既有存档。

### 变更明细

- 战报逐条播出：出征结算后页内战报区逐条入场（复用气泡入场
  动画），间隔基准 220 毫秒并按条数自适应收紧，播放段总时长
  封顶约 4 秒；跳过提示小字随播出显示
- 跳过：点击战报区或按 Esc 立即补全整份战报并弹出结果弹窗
- 播放期出征按钮禁用防连点；离开页面自动清理播放定时器
- 减动效：减弱动画偏好下不播出，结算后弹窗即出
- 战报仅 1 条（空编成等快速失败）时同样直出弹窗
- 语言包：双语各新增 1 键（1306 至 1307）
- 动效规范：战斗过程演出登记（时长总表、降级表与关键帧复用
  注记）

### 验证

- check 全绿：56 个测试文件 765 个用例（新增 4 条：播出递增与
  弹窗延后、跳过补全、减动效直出、播放期防连点）+ 计数守恒 +
  文案守卫 + lint/format
- 端到端：新专项 starcore-v156-battle-replay（逐条播出 / 点击
  跳过 / Esc 跳过 / 减动效四段 14 校验）；套件 37 升 38、
  重跑集 27 升 28；既有战斗锚点由固定等待改为弹窗条件等待
  （v060 / v082 / v117 / v124 / v133 共 12 处）
- 部署前套件 38/38 + 部署后线上重跑 28/28 + index/app
  双分块 sha256 逐字节一致
- 双视口截图目检：播出中、播完弹窗、跳过与减动效形态

## v1.55 — 功能: 节点仪式感演出（转生、层完成与终局仪式）


**变更性质：功能（为转生与探索里程碑新增仪式演出，机制与数值零变化）**

**开发时间：2026-10-11**

### 概述

此前确认奇点重启后进度即时重置、星图层探索完毕无任何提示，
放置循环的高光时刻缺少反馈。本版为转生、每层探索完毕与
全宇宙探索完毕（终局）新增仪式演出，复用既有跃迁白光与
弹窗手法。游戏机制、数值与存档格式零变化，兼容既有存档。

### 变更明细

- 转生仪式：确认奇点重启后播放全屏演出（白光闪场 + 仪式卡），
  展示获得负熵与重启次数；点击任意处或约 4 秒自动关闭，
  随后进入新一轮
- 层完成横幅：星图每层探索完毕时顶部弹出层色横幅
  （层名 + 完毕文案），约 3.5 秒自动消失、点击提前关闭；
  同层不重复播放，读档恢复不补播，转生重置后可再次触发
- 终局仪式：深空层完成（全宇宙 34 节点探索完毕）时不播普通
  横幅，改播全屏仪式（终章贺词文案）；首页静态贺词保留
- 结构：新增 CeremonyOverlay（转生 / 终局通用底座）与
  LayerCompleteCeremony（队列消费与横幅）两组件；层完成
  跳变沿检测入 exploration store（completedLayers 防复播、
  读档静默登记、reset 随探索清空）
- 语言包：双语各新增 3 键（1303 至 1306）
- 减动效：闪场与入场动画由全局规则瞬时降级，仪式卡静态可读
- 动效规范：仪式演出登记（时长总表、降级表与关键帧复用注记）

### 验证

- check 全绿：56 个测试文件 761 个用例（新增 13 条：层完成
  沿检测 6、转生仪式 2、层完成仪式组件 5）+ 计数守恒 +
  文案守卫 + lint/format
- 端到端：新专项 starcore-v155-ceremony（转生仪式 / 层横幅 /
  终局仪式 / 减动效降级四段 14 校验）；套件 36 升 37、
  重跑集 26 升 27；v057 与 v133 转生流适配仪式关闭步骤
- 部署前套件 37/37 + 部署后线上重跑 27/27 + index/app
  双分块 sha256 逐字节一致
- 双视口截图目检：转生仪式、层完成横幅、终局仪式三形态

## v1.35 — 功能: 存档完整性签名与存档导出格式更新


**变更性质：功能（存档校验和升级为带密钥签名，导入仅接受新格式）**

**开发时间：2026-09-29**

### 概述

存档链路的校验和由无密钥的 fnv1a 哈希升级为带密钥的 HMAC 签名，
摘要算法为 SHA256，密钥由代码内多段碎片现场派生，构建产物文本中
不存在完整密钥。修改存档数据将无法伪造合法签名，解 base64 改数
字重新导入的存档修改器路线失效；剩余路径为逆向提取密钥与控制台
改运行时内存，属浏览器复杂操作档。导出格式升级为 SCB1- 前缀，
旧格式本地档与旧导出码不再接受。

### 变更明细

- 签名实现：新增 integrity 模块，纯 TS 实现 SHA256 与 HMAC，不
  依赖 Web Crypto，读写链路保持同步语义；验签入口用常量时间比较
  防逐位试探；密钥派生输入不含版本串与游戏数据表常量，导出档跨
  版本可导入，调平衡不导致存量档验签漂移。
- 本地读写：双通道写路径载荷签名换新实现；读路径硬切，旧哈希载
  荷与裸对象档一律判损坏进错误屏，可导出原始档后清除重开。测试
  期无真实玩家，不留迁移宽容。
- 导入导出：导出升级 SCB1- 前缀，载荷为带签名 JSON 再编码；导入
  仅接受 SCB1- 且验签通过，旧 SCB- 与 SCE- 前缀一律拒绝，旧导出
  码须重新导出。结构校验与版本口径零变化，存档结构无迁移。
- 兼容性：升级后首个版本的读取会对旧本地档报存档损坏，经错误屏
  导出原始档并清除重开即可；旧导出码导入提示存档无效，重新导出
  后恢复可用。

### 验证

- 构建通过，四十七文件六百九十一用例全过，计数守恒全绿含
  Playwright 段，文案守卫五项零违规，lint 与 format 零输出
- 标准向量：RFC 4231 四组与 FIPS 180-4 示例全对，含长密钥先哈希
  分支；篡改载荷任一字节验签失败、旧前缀导入拒绝均有用例断言
- 回归套件三十五脚本全过，含存档签名专项十八项校验；线上重跑见

## v0.95 — 修复: 错误屏出口可靠性与运行期兜底


**变更性质：修复（错误屏出口、下载可靠性、运行期兜底、显示与导航交互）**
**开发时间：2026-09-15**

### 概述

错误屏的两个出口此前在失败路径上不可观测：导出损坏档时下载链接
未挂入文档，对象地址在点击后同步回收，部分浏览器可能在下载开始

裸抛，界面表现为「点了没反应」，没有任何反馈。本次改为链接入
文档后延迟回收对象地址，清除失败给出可见提示，并对进行中的清除
请求加防重入。

应用此前没有全局错误兜底，渲染、生命周期或事件处理中的未捕获
异常只打印到控制台，页面停在半渲染或空白状态，玩家没有出口。

页面、导出存档与清除存档重开三种出口，屏上标题与提示按存档
读取三态与运行期异常分别切换。

数值格式化此前对 number 与 Decimal 两种入参走两套路径：number
路径按引擎原生四舍五入，Decimal 路径按全局截断配置取数，同一
数值会因传参类型显示不同结果；负值在小数量级会越过单位边界，
如 -999.5 显示为 -1000 而 -1000 显示 -1K，形成断层；极小负值
显示 -0；超出最大后缀档的科学计数法残留尾零。本次把 fmt 统一为
单一 Decimal 路径，负数侧改朝零截断并归一负零，科学计数法统一
去尾零，pct 同步归一负零。

成就页「已获得加成」此前把各成就的标注值直接相加，与实际生效的
连乘口径不一致，系统性低报各面加成；部队页「全军战力」与部队卡

系统实际生效值同源；全军战力与「已拥有」改用库存加编队的全量
口径，空状态判定同步。战斗页敌方部署的攻击、防御与血量及编队
战力此前裸数字输出，大数值下出现指数记号，统一接入 fmt 管线。

导航层此前有三处缺陷：桌面侧栏折叠后标签只做透明处理仍占布局，
把导航图标压缩至零宽，折叠态整列图标不可见；战斗页不属于任何
导航层级，上下导航却把当前位置回退标记为「主界面」并高亮，对
视觉与读屏都是错误导向；移动端「更多」面板打开后不能用 Escape
收起，也没有与触发按钮的关联语义，读屏用户无从得知展开的是哪

路由不再回退高亮，「更多」面板补键盘关闭与关联语义。

## v0.94 — 修复: 战斗核心校验与奖励发放时机


**变更性质：修复（远征模板校验、奖励即时发放、批量预览与周挑战补掷）**
**开发时间：2026-09-14**

### 概述

无尽远征的模板据点若被改名或删除，会同时触发两条静默降级：编成
函数返回空数组，在战斗结算中被空数组遍历误判为胜利；其余模板的
强度归一化系数退化为基准值，敌人数值被放大数个量级，这类配置
错误此前没有任何暴露出口。远征深度选择此前只跟随历史最深加 1，
不与最大深度上限对齐，理论极限下可选到不记纪录的「假前沿」层数。
战斗胜利奖励此前推迟到结果弹窗的按钮动作才发放，弹窗打开期间
刷新或离开页面会留下已计入的攻克状态、已扣的战损与未发放的奖励，
战果永久丢失且无补领入口。本次将模板校验改为加载即抛错快速失败、
深度按上限封顶、奖励改为战斗结算时即时发放、弹窗只做展示，并
统一结果弹窗的遗物稀有度文案为中文名。

批量升级段位（×10/×100）此前只显示单级成本，一次点击按买满
语义逐级累计扣费，屏幕数字与实际扣费可差数倍；本次为建筑
升级与转生树无限天赋补批量预览，段位大于 1 时展示实际可买
级数与预计总花费。建筑等级上限此前只由视图与行动队列各自
判定，升级操作不校验，数据启用上限后会越限购买；本次将上限
判定下沉为 store 单一门槛并在扣费前拦截。转生确认弹窗的重置
与保留清单漏掉据点攻克记录、驻扎状态与成就保留，本次补齐与
转生实际行为对齐。

周挑战在「周标识已是当前周但列表为空或不足 3 条」的退化或外部
存档下此前不补掷，空表被原样写回，整周无挑战可做；本次把完整性
判定并入重掷条件，列表不完整即按周种子重掷补全，同周补掷保留
计数，跨周仍照常清零。测试侧原按运行周分支的往返校验改为真实

## v0.81 — 修复: 存档安全链：损坏档保护与校验收紧


**变更性质：修复（存档读写链路六项缺陷收尾，其中一项可致数据丢失）**
**开发时间：2026-09-09**

### 概述

数值串校验曾接受任意位指数，注入超长指数可让无限大写进存档，下次读
档整档判废；损坏档与无档不可区分，读档失败后静默开新档，自动存档即
覆盖原始数据。本版双道收紧数值校验并为损坏档新增专门状态与错误屏，
提供导出原始存档出口；顺路收尾同测试面的六项校验与编码卫生。存档结
构零变化，版本号不变，旧档无感兼容。

### 变更明细

- 数值串指数限位：
  - 科学计数法指数位数限 1 到 6 位，超长指数在校验层直接拒档
  - 负熵反序列化增加有限性兜底，非有限值钳 0，两道防线共同杜绝
    无限大经序列化写进存档
- 损坏档专门状态：
  - 读档结果新增损坏态，与无档严格区分；仅当双通道确实存在存
    储值但全部不可读时报损坏，主备双档取保存时间更新的一档
  - 损坏态进入错误屏，提供导出原始存档（原始载荷原样下载）与
    清除存档重开两个出口
  - 错误态下一切存档写入被拒绝，自动存档与关闭页面前的同步存
    档均不再覆盖原始数据
- 转生树幂聚合：
  - 无限节点效果不再按等级逐份展开物化数组，改为单条携带等级
    的聚合条目，乘数型按值取幂、加法型按值乘等级，语义等价
  - 配合无限节点等级硬上限（百万级，正常进度不可触顶），超限
    存档在校验层拒绝，超大等级值不再可能挂死首帧
- 导入替换语义：
  - 导入存档前先全量重置各 store 再写入，缺省字段回落初始值
  - 转生次数为 0 可正常清零，不再保留内存现值
- 编队自愈：
  - 空编队数组在校验前按默认三支编队补齐
  - 战斗页对越界编队选择回退首支，异常档不再触发页面崩溃
- 校验与编码卫生：
  - 训练任务数量必须为非负整数（小数曾可入档并在完成时产出小数
    兵力致整档判废），转生次数必须为非负整数
  - 导入编解码改用标准文本编码接口替换已废弃的转义函数，中文与
    表情符号导出导入往返无损，旧导出码互通
  - 多处注释与实现口径对齐
