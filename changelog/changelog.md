## v1.58 — 功能: 随机遭遇扩容至 25 模板（奖励词汇扩展与回执修正）

**变更性质：功能（事件池扩容与奖励词汇扩展，既有模板数值零变化）**

**开发时间：2026-10-12**

### 概述

随机遭遇事件池自 v1.26 上线以来保持 10 个模板，重复度偏高。本
版将事件池扩容至 25 个，新增 15 个覆盖五资源与多档风险口味的
模板，并扩展奖励词汇：晶体首次进入事件奖励，兵员收编新增护卫
兵与重装兵两型。收编结算回执由资源 ID 占位改为显示兵种名。既
有 10 个模板的数值、事件 ID 与结算逻辑零变化，兼容既有存档。

### 变更明细

- 事件池 10 到 25：资源类 4 到 9、军事类 2 到 5、探索类 1 到 3、
  赌注类 3 到 8；新增模板全部通过 EV 核验表五门断言，两选项期
  望差上限 13.4%、折算当量落 4.4e3 到 9.2e3、赌注类高方差与
  资源类低方差签名保持拉开
- 奖励词汇扩展：晶体可作事件奖励，落于晶体矿簇与晶体母矿两个
  模板；收编兵员新增护卫兵与重装兵，落于废弃兵营与重装残队两
  个模板，结算按兵种分派入库存
- 回执修正：遭遇结算回执对收编结果显示兵种名，替代资源 ID 占位
- 文案与文档：中英双语各新增 60 键，语言包总数 1307 到 1367；
  数值设定规范与设定架构册同步
- 兼容性：事件 ID 与存档格式不变，无需迁移；触发间隔与过期
  判定不变

### 验证

- check 全绿：56 个测试文件 765 个用例；计数守恒、文案守卫双语
  各 1367 键、lint 与格式检查全部通过
- 数值：EV 核验表 25 模板全部断言通过
- 回归：部署前套件 38/38、部署后线上重跑 28/28；专项探针 4/4
  预览与线上双端通过
- 产物：index 与 app 双分块 sha256 与线上逐字节一致

## v1.57 — 修复: 随机事件文案修正（措辞澄清与术语统一）

过重的表述，玩家读不出每个选项在做什么。本版对十个模板的玩家
可见文案逐条梳理，修正其中易误读的表述，数值、事件数量与结算
逻辑零变化，兼容既有存档。

  数据核心与能源核心，与既有核心词族同形
- 语言包：中英双语同步更新，键位与数量不变；数值核验脚本的镜
  像文案同步，重跑全部断言通过
- 兼容性：事件 id、结算逻辑与存档格式不变，无需迁移

## v1.56 — 功能: 战斗过程演出（战报逐条播出）

**变更性质：功能（战报逐条播出、结果弹窗延后出场，机制数值零变化）**

**开发时间：2026-10-11**

### 概述

此前点击出征后结果弹窗与完整战报同帧出现，战斗缺少过程感。
本版让页内战报逐条播出：日志按条入场，播完或跳过后结果弹窗
才出场；奖励与战损仍在结算时即时落袋，机制与数值零变化，
兼容既有存档。

### 变更明细

- 战报逐条播出：出征结算后页内战报区逐条入场（复用气泡入场
  动画），间隔基准 220 毫秒并按条数自适应收紧，播放段总时长
  封顶约 4 秒；跳过提示小字随播出显示
- 跳过：点击战报区或按 Esc 立即补全整份战报并弹出结果弹窗
- 播放期出征按钮禁用防连点；离开页面自动清理播放定时器
- 减动效：减弱动画偏好下不播出，结算后弹窗即出
- 战报仅 1 条（空编成等快速失败）时同样直出弹窗
- 语言包：双语各新增 1 键（1306 至 1307）
- 动效规范：战斗过程演出登记（时长总表、降级表与关键帧复用
  注记）

### 验证

- check 全绿：56 个测试文件 765 个用例（新增 4 条：播出递增与
  弹窗延后、跳过补全、减动效直出、播放期防连点）+ 计数守恒 +
  文案守卫 + lint/format
- 端到端：新专项 starcore-v156-battle-replay（逐条播出 / 点击
  跳过 / Esc 跳过 / 减动效四段 14 校验）；套件 37 升 38、
  重跑集 27 升 28；既有战斗锚点由固定等待改为弹窗条件等待
  （v060 / v082 / v117 / v124 / v133 共 12 处）
- 部署前套件 38/38 + 部署后线上重跑 28/28 + index/app
  双分块 sha256 逐字节一致
- 双视口截图目检：播出中、播完弹窗、跳过与减动效形态

## v1.55 — 功能: 节点仪式感演出（转生、层完成与终局仪式）

**变更性质：功能（为转生与探索里程碑新增仪式演出，机制与数值零变化）**

**开发时间：2026-10-11**

### 概述

此前确认奇点重启后进度即时重置、星图层探索完毕无任何提示，
放置循环的高光时刻缺少反馈。本版为转生、每层探索完毕与
全宇宙探索完毕（终局）新增仪式演出，复用既有跃迁白光与
弹窗手法。游戏机制、数值与存档格式零变化，兼容既有存档。

### 变更明细

- 转生仪式：确认奇点重启后播放全屏演出（白光闪场 + 仪式卡），
  展示获得负熵与重启次数；点击任意处或约 4 秒自动关闭，
  随后进入新一轮
- 层完成横幅：星图每层探索完毕时顶部弹出层色横幅
  （层名 + 完毕文案），约 3.5 秒自动消失、点击提前关闭；
  同层不重复播放，读档恢复不补播，转生重置后可再次触发
- 终局仪式：深空层完成（全宇宙 34 节点探索完毕）时不播普通
  横幅，改播全屏仪式（终章贺词文案）；首页静态贺词保留
- 结构：新增 CeremonyOverlay（转生 / 终局通用底座）与
  LayerCompleteCeremony（队列消费与横幅）两组件；层完成
  跳变沿检测入 exploration store（completedLayers 防复播、
  读档静默登记、reset 随探索清空）
- 语言包：双语各新增 3 键（1303 至 1306）
- 减动效：闪场与入场动画由全局规则瞬时降级，仪式卡静态可读
- 动效规范：仪式演出登记（时长总表、降级表与关键帧复用注记）

### 验证

- check 全绿：56 个测试文件 761 个用例（新增 13 条：层完成
  沿检测 6、转生仪式 2、层完成仪式组件 5）+ 计数守恒 +
  文案守卫 + lint/format
- 端到端：新专项 starcore-v155-ceremony（转生仪式 / 层横幅 /
  终局仪式 / 减动效降级四段 14 校验）；套件 36 升 37、
  重跑集 26 升 27；v057 与 v133 转生流适配仪式关闭步骤
- 部署前套件 37/37 + 部署后线上重跑 27/27 + index/app
  双分块 sha256 逐字节一致

## v1.54 — 重构: 主 store 编排层拆分为三件支撑模块

**变更性质：重构（纯结构拆分，行为与界面零变化）**

**开发时间：2026-10-10**

### 概述

主 store game.ts 此前集中跨系统奖励发放、原子操作与自动化、
转生协调等编排职责，随玩法增加持续增长（625 行）。本轮沿用
game-effects 与 game-persistence 的既有形态，把编排层拆为
三件支撑模块，game.ts 保留子 store 装配、tick 主循环与
生命周期，导出契约不变。游戏机制、数值与存档格式零变化，
玩家侧无感知。

### 变更明细

- 结构拆分：
  - 新增 `src/stores/game-rewards.ts`（124 行）：每日挑战领取、
    随机遭遇结算发放、派遣解锁同步与到点结算、远征里程碑领取
  - 新增 `src/stores/game-actions.ts`（191 行）：建筑升级与
    科技研究原子操作、批量升级与批量强化预览、建造 / 研究 /
    探索三协议自动化
  - 新增 `src/stores/game-transcend.ts`（124 行）：转生门槛
    判定、收益预览与执行
  - `src/stores/game.ts` 由 625 行减至 437 行：子 store 装配
    与依赖注入、终身计数采集、tick 主循环、生命周期、导出表
- 工厂模式沿用既有约定：三件模块各自导出 create 函数，由
  game.ts 在 setup 阶段传入 store 实例与乘数 computed，store 间
  不新增直接互引；视图与测试零改动
- 文档同步：《游戏设定与架构》技术架构节补编排层支撑模块清单

### 验证

- check 全绿（build 含类型检查 + test 55 文件 748 用例 +
  计数守恒 + 文案守卫 + lint + format）
- 部署前端到端套件 36/36，部署后线上重跑 26/26
- index / app 双分块 sha256 与线上逐字节一致

## v1.53 — 修复: 语言包未就绪取词加开发态断言

**变更性质：修复（开发期断言，玩家侧零变化）**

**开发时间：2026-10-10**

### 概述

数据表与 store 在模块求值期取词，依赖「语言包先于应用主体
装载」的入口顺序约定。此前约定被打破时 t() 静默返回键名且
固化在模块实例里，排查困难。本版加开发态断言：语言包未
就绪时 t() 在开发与测试态直接抛错并指引装载入口，生产态
维持返回键名兜底。

### 变更明细

- i18n 门面：t() 未就绪守卫，开发与测试态抛错、生产态兜底
- 测试：新增 3 个用例钉住未就绪抛错、装载后恢复、缺键返回
  键名的边界，含未就绪时导入数据表在求值期即抛错
- 文档：游戏设定与架构册多语言节同步守卫口径

### 验证

- 构建、测试、计数守恒、文案守卫、lint 与格式检查全部通过
  （55 个测试文件 748 个用例）
- 本地回归套件 36 个脚本与线上重跑 26 个脚本全部通过
- 产物双分块与线上逐字节一致
