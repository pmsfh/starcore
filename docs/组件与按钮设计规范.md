## Hero 核心区重构视觉稿

> **实现注记（v1.40-v1.42 改版）**：Hero 核心区经三版演进：核心缩至 110/130px 并新增五资源节点正五角形环绕（v1.40）；中央圆形视觉整体移除（v1.41）；五资源节点改为圆形徽章，移动 88px、桌面 100px，舞台 280×272、328×320（v1.42）。本章各表、代码块与验收清单为改版前设计稿：`.core-visual`、`.core-ring`、`.core-value`、`.core-label` 与圆心产出率均已不存在；点击与键盘跳转由 `.hero-stage` 承接，无障碍名称随形态更新。现行参数以 `HeroCore.vue` 实现为准。 v1.60：中央新增「星核微光」焦点锚（低频呼吸渐晕，登记《动效规范》§4.7）；引导步激活时 Hero 顶部动态留位，防气泡遮挡资源节点。

### 1.1 设计目标

将 Hero 核心区从「160px 小贴图」升级为「200/240px 沉浸式能量体」，实现：
- 尺寸放大 → 首屏视觉焦点确立
- 光晕渗透 → 核心与背景融为一体，而非贴纸
- 交互化 → 点击核心跳转建造页
- 产出率规范化 → 14px + "/s" 后缀

## 行动队列合并视觉稿

### 2.1 设计目标

将 HomeView 现有的「活跃事件」（`activeEvents`）和「推荐行动」（`suggestions`）两个独立 section 合并为单一「行动队列」模块，内部按状态分为两类视觉语言：

- **进行中** — 有进度条 + 脉冲 box-shadow，暗示「正在发生」
- **可执行** — 图标色块 + hover 上浮，暗示「可以去做」

### 2.2 数据结构映射

前端现有数据源（HomeView.vue `activeEvents` / `suggestions` computed）合并为统一队列：

```typescript
// 合并后的行动队列数据结构（前端实现参考）
interface ActionItem {
  id: string
  label: string
  detail: string
  path: string
  color: string         // 主题色
  icon: string          // symbol id
  status: 'in-progress' | 'actionable'  // 两类视觉语言
  progress?: number     // 0~1，仅 in-progress 有
}
```

**数据映射规则**：

| 来源 | 原状态 | 新 status | 判定条件 |
|------|--------|-----------|---------|
| `activeEvents` 中 `progress < 1` | 探索中/训练中 | `in-progress` | 有进度条 |
| `activeEvents` 中 `progress >= 1` | 可升级/可研究 | `actionable` | 资源已够 |
| `suggestions` 全部 | 推荐行动 | `actionable` | 情境推荐 |

**排序规则**：`in-progress` 优先 → `actionable` 按优先级（建筑 > 科技 > 探索 > 军事）

**队列容量**：进行中全保留；可执行项按排序补足至总数 6，进行中已达到或超过 6 时不显示可执行项（`useActionQueue` 单一实现）。

| 维度 | 进行中 (in-progress) | 可执行 (actionable) |
