# 星核纪元 · UI 回归体检清单

> **触发时机**：UI 类版本（版本标题为「UI:」或包含可见样式改动）随版例行执行一次，首跑结果归档为该版本基线报告；修复类版本与纯文档 / 工程版本不触发。
> **依据**：硬编码色值口径见《设计令牌规范》§1.6；字号豁免见 §2.3.4；动效时长唯一出处为《动效规范》§五时长总表；间距跳档口径见《设计令牌规范》§四。
> **执行方式**：三节检索式 + 一节人工核对逐条在仓库根目录执行，任一节不满足通过标准即阻断发版；每次首跑结果作为该版本基线留档。

## ① 字面色值 diff（对照令牌规范 §1）

**检索式**：

```bash
rg -n "#[0-9a-fA-F]{3,8}\b|rgba?\(" src/ --glob="*.{vue,css,ts}" -g '!src/styles/tokens.css' -g '!src/styles/fonts.css'
```

**通过标准**：

- src 样式与数据层不写裸色值；色彩一律经令牌引用（含 `color-mix()` 内的 `var(--color-*)`）。
- 登记在案的例外仅两处：`tokens.css` / 字体定义文件自身、`index.html` 首屏装载段内联样式（装载期先于外部样式，色值随令牌同值维护）。
- 检索命中若出现第三处裸色值，须先在《设计令牌规范》登记令牌或豁免后再落码，否则判违规。

## ② 字号扫描（对照 §2.2 映射表）

**检索式**：

```bash
rg -n "font-size\s*:\s*\d+px" src/ --glob="*.{vue,css}"
```

**通过标准**：

- 唯一合法命中：`src/styles/utilities.css` 的 `.section-title { font-size: 17px }`（主标题级，全项目唯一刻意保留的硬编码字号，令牌表无 17px 档位）。
- 其余字号一律经 `--text-*` 七级令牌引用；出现其他字面字号（含 10px 回潮）即判违规。
- 新增字号需求先对照 §2.2 映射表取最近档位，确需新档位则先扩令牌表。

## ③ 动效时长对照（时长总表为唯一出处）

**检索式**：

```bash
rg -n "(animation|transition)[^;]*[0-9.]+(ms|s)\b" src/ --glob="*.{vue,css}"
```

**通过标准**：

- 每一处玩家可见动效时长都能在《动效规范》§五时长总表（或对应章节登记）找到同值条目；无表外时长。
- 时长令牌化后，裸值正则不覆盖 `var(--duration-*)`；另需人工核对令牌使用点是否在时长总表登记。
- 新增动画先在时长总表登记（时长 / 类别 / 使用点 / 定标说明）再落码。
- 缓动统一 `var(--ease-out)`，循环动画用 ease-in-out 或 linear；定标原则：交互反馈 ≤ 0.3s、事件反馈 ≤ 0.6s。
- `prefers-reduced-motion` 降级路径与全局瞬时化规则不属时长新增，无需登记。

## ④ 豁免核对（既有豁免清单逐条核对）

既有豁免清单（截至 v1.66）：

| 豁免项 | 内容 | 登记处 |
|---|---|---|
| 字阶唯一豁免 | `.section-title` 17px | 《设计令牌规范》§2.3.4 |
| 按钮动效豁免 | `.btn-transcend` active `scale(0.97)` / 0.15s、disabled `opacity: 0.5` | 《动效规范》§1.3 豁免注记 |
| 字面色值豁免 | 令牌与字体定义文件自身、`index.html` 首屏装载段内联样式 | 《设计令牌规范》§1.6 |
| 间距跳档口径 | 24→40 跳档合法（`--space-7` 定案不实现） | 《设计令牌规范》§四 |

**通过标准**：

- 逐条核对：豁免值无新增扩散（无新增文件 / 选择器引用豁免值）。
- 豁免仍为「既有实现认可保留」，新代码不得参照豁免值落笔。
- 需要新增豁免时，先在对应规范登记条目，再同步扩充本表。

## 附：宽屏双列孤卡与奇数末卡策略（v1.70 登记）

宽屏双列网格列表统一跨列策略（档案馆为孤卡先例，星图与转生树本版
补齐奇数末卡，与实改规则一字对齐）：

- 孤卡分组跨列：`:only-child` 跨双列，避免右列留黑（档案馆 v1.60 先例，
  星图轨道带 / 内层星系 / 外层星系 / 深空带四个单节点层沿用）；
- 奇数末卡跨列：`:last-child:nth-child(odd)` 同跨双列，奇数总数末卡
  不再独占左列留白右列（如 19 据点态）；偶数总数不受影响；
- 跨列卡文本行限宽 68ch：文本行不拉满全宽，保持阅读节奏；子组件内部
  文本行须经 `:deep()` 穿透命中（scoped 规则限制，子组件根节点外不带
  父作用域标记）；
- 转生树双列为预置兜底：当前两树节点数均为偶数零视觉变化，未来增节点
  不再出现右列留白；
- 新增双列列表随版套用本策略，不再个案决策。

已知登记项：科技页双列 gap 为 `--space-3`（v1.37 既有节律，宽卡两行式），
与列表型页面 `--space-2` 差异为已知登记项。
